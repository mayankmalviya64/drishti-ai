# Drishti AI

**See every ad leak before it costs you.**

Live site: https://mayankmalviya64.github.io/drishti-ai/

One page that explains the idea and lets you try it:

1. **Problem** – the ad buyer's decision loop (today vs with Drishti) and the four failures underneath.
2. **Connect the data** – switch data pipelines on and see which recommendations each combination unlocks.
3. **Agents** – P1–P5 plus the Orchestrator, tiered autonomy, and why this needs agents.
4. **Playground** – a live one-week holdout simulation. Inject disruptions (pandemic, IPL, tracking break, stockout…), watch Drishti think and act, and approve or reject its big moves.
5. **Try your data** – paste or type your channels, cohorts and ads; get true ROAS, fatigue scores, a budget shift and an action plan, then send them into the playground.
6. **Connectors**, **self-grading (AHI)** and **impact**.

## Files

| File | What it does |
|---|---|
| `index.html` | Page structure and story text |
| `style.css` | Styles; light theme by default, dark theme via the 🌙 button |
| `sim.js` | Playground simulator (market model, agents, approvals, reports) |
| `story.js` | Explanatory visuals (loop, pipelines, agents, connectors, AHI calculator) |
| `byod.js` | "Try your data" analysis |

Everything runs in the browser; no data leaves the page. Brands are fictional and figures are illustrative unless referenced.
